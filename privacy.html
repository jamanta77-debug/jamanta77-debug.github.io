Privacy Policy

Last updated: November 24, 2026

Overview

MuseSync (the "Application") is a personal automation tool operated by the application owner for the owner's own use only. It is not offered to the public and has no other users.

What the Application accesses

With the owner's authorization, the Application accesses:

  • Google Drive: to read and write files in the owner's "MuseSync" folder (daily digest files)
  • Google Calendar: to read the owner's calendar events for inclusion in the owner's daily digest

How the data is used

The accessed data is used solely to generate a daily digest file for the owner and to store that file in the owner's own Google Drive. The data is not sold, not shared with third parties, not used for advertising, and not used to train machine learning models.

Data storage and security

OAuth credentials are stored as an encrypted secret in the owner's GitHub repository (GitHub Actions Secrets) and are used only when the scheduled automation runs. No other copy of the credentials is distributed.

Data retention and deletion

Digest files remain in the owner's Google Drive under the owner's control and can be deleted by the owner at any time. The owner can revoke the Application's access at any time from the Google Account permissions page (https://myaccount.google.com/permissions), which immediately stops all access.
